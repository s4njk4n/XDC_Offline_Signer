Sign XDC transactions on an offline computer

This page is self-contained and cannot make any network connection, even if the computer is online. Your key stays in this browser tab's memory and is never saved. Close the tab when you are done.

This computer reports a network connection. The page itself is blocked from using the network, but the safest setup is a computer whose Wi-Fi and Bluetooth are removed or disabled and which is never connected again.

1

Load your key

Use the private key, keystore file or recovery phrase of the wallet you are moving funds from.

Passphrase and derivation path

Addresses are this path followed by /0, /1, /2… Put i where the account number goes if it isn't at the end, for example m/44'/60'/i'/0/0.

With a signing request loaded, the signer searches every path the XinFin web wallet has ever offered (32 of them), plus your custom path, for the request's address. Without one, it uses the path and index above.
